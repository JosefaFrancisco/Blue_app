# Aplicación Móvil de Gestión de Artículos

Este repositorio contiene el código fuente de una aplicación móvil nativa desarrollada para la plataforma Android. El proyecto está enfocado en la gestión de registros (CRUD), la validación de usuarios y la persistencia de datos mediante la comunicación con un servidor externo.

## Funcionalidades Principales

* **Desarrollo Nativo Android:** Implementación de interfaces interactivas y componentes modernos utilizando Android Studio y Jetpack Compose.
* **Flujo de Operaciones CRUD:** Desarrollo de vistas y lógica de negocio para permitir el registro, consulta, actualización y eliminación de artículos en el sistema.
* **Control de Acceso:** Módulo dedicado al registro seguro de nuevos usuarios y validación de credenciales para el inicio de sesión.
* **Conexión de Datos Externa:** Integración y comunicación con una base de datos MySQL mediante el consumo de una interfaz de programación de aplicaciones (API).

## Tecnologías Utilizadas

* **Lenguaje de Programación:** Kotlin
* **Herramientas de UI:** Jetpack Compose, Android Studio
* **Base de Datos Relacionada:** MySQL (vía API externa)
* **Control de Versiones:** Git y GitHub

## Estructura del Proyecto

El código fuente está organizado bajo los estándares de desarrollo nativo en Android para asegurar un correcto ciclo de vida de la aplicación y facilitar su mantenimiento:
* **UI y Componibles:** Definición de las pantallas de la aplicación, layouts responsivos y manejo de estados de la interfaz.
* **Conectividad:** Lógica encargada de realizar las peticiones de red hacia el servidor para sincronizar los datos de los artículos y usuarios.
